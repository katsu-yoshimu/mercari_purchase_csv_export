# mercari_purchase_csv_export
メルカリ購入履歴 CSV エクスポート

メルカリの購入履歴ページおよび取引詳細ページを Selenium で解析し、
指定した日付範囲の購入履歴を **CSV ファイルとして出力** する Python ツールです。

---

## 特徴

* Selenium によるブラウザ操作（手動ログイン対応）
* 購入履歴を日付範囲で抽出
* 降順前提で高速終了（From 日付を下回った時点で処理終了）
* CSV 出力（Excel 互換、ダブルクォート・カンマ安全）
* 取引詳細ページ **2パターン対応**
* PEP8 準拠

---

## 動作環境

* OS : Windows 11
* Python : **3.14**
* Browser : Google Chrome
* ChromeDriver : Chrome のバージョンに対応したもの

## 実行方法

```powershell
python mercari_purchase_csv_export.py \
  --from-date 2026/01/16 \
  --to-date 2026/01/17 \
  --csv-path 購入履歴.csv
```

### 引数一覧

| 引数            | 内容                       | 省略時        |
| ------------- | ------------------------ | ---------- |
| `--from-date` | 出力対象 From 日付（yyyy/mm/dd） | 本日   |
| `--to-date`   | 出力対象 To 日付（yyyy/mm/dd）   | From 日付   |
| `--csv-path`  | 出力 CSV ファイルパス            | `購入履歴.csv` |

---

## 処理の流れ

1. Chrome を Selenium で起動
2. メルカリのログインページを表示
3. **手動でログイン**
4. 購入履歴ページを表示
5. Enter キーで処理再開
6. 購入履歴を解析
7. 日付範囲に該当する明細のみ抽出
8. 明細ごとに取引詳細ページを表示＆解析 ※時間かかる処理。明細ごとに3秒の待ち時間あり
9. CSV ファイルを作成
10. 処理結果をコンソールに表示

## CSV 出力仕様

### 出力項目

| 項目名       | 内容                 |
| --------- | ------------------ |
| No.       | 1 からの連番            |
| 商品名       | 購入履歴ページから取得  |
| 金額        | 取引詳細ページから取得       |
| 購入日時      | `yyyy/mm/dd HH:MM` |
| 商品ID／注文番号 | 取引詳細ページから取得  |

※ 明細が 0 件の場合でも **ヘッダのみの CSV** を作成します。

---

## 購入履歴ページ解析仕様

### 明細一覧取得 XPATH

```xpath
//ul[@data-testid="purchase-item-list"]/li
```

購入履歴は **購入日時の降順** で表示される前提です。

---

### 購入履歴ページ：取得項目と XPATH

| 項目    | XPATH                                                          | 備考                 |
| ----- | -------------------------------------------------------------- | ------------------ |
| 詳細URL | `./a/@href`                                                    | 取引詳細ページへのリンク       |
| 商品名   | `.//p[@data-testid="item-label"]`                              | 商品タイトル             |
| 購入日時  | `.//p[@data-testid="item-label"]/following-sibling::div//span` | `yyyy/mm/dd HH:MM` |

### 購入日時の扱い

* 表示例

  ```
  2026/01/16 13:52
  ```
* datetime として解析し、
  以下条件を満たす場合のみ出力対象とします。

```text
From 日付 <= 購入日時 <= To 日付
```

* 購入日時が **From 日付より古くなった時点で処理終了**

---

## 取引詳細ページ対応仕様

取引詳細ページは **2 パターン**存在しますが、
以下の XPATH により吸収しています。

### 取得項目と XPATH

| 項目   | XPATH                                                                                                                                                          |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 金額   | `//span[contains(text(), "商品代金")]/parent::div/parent::div/following-sibling::div`<br>または<br>`//p[contains(text(), "商品代金")]/parent::div/following-sibling::div` |
| 商品ID | `//p[@data-partner-id="item-id"]`                                                                                                                              |
| 注文番号 | `//p[contains(text(), "注文番号")]/parent::div/following-sibling::div//p`                                                                                          |

* 要素が存在しない場合は **空文字**
* 複数要素が存在する場合は **すべて連結**
